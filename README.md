## ✨ Почему XPance?

Большинство приложений для учета финансов либо требуют подписку и хранят ваши банковские тайны на чужих серверах, либо превращают запись трат в скучную рутину.

**XPance** решает обе проблемы:
1. **Данные принадлежат только вам**: архитектура **Local-First** хранит всю историю локально на вашем телефоне или компьютере. Никаких чужих баз данных.
2. **Охота на неразумные траты вместо самобичевания**: траты делятся на 3 категории осознанности, а дисциплина вознаграждается стриками, очками опыта (XP) и трофеями.
3. **Мультивалютный капитал**: карты разных банков и валюты пересчитываются в единый сводный капитал (Net Worth) в реальном времени.

## 🚀 Ключевые возможности

### 1. 🌿 Радар осознанности (Impulse vs Rationality)
Каждый расход помечается одним из трёх тегов в один клик:
* 🌿 **Base (База)** — необходимые жизненные расходы (жилье, продукты, транспорт, здоровье).
* ✨ **Joy (В радость)** — осознанные траты для души и качества жизни (путешествия, ужины, хобби).
* ⚠️ **Impulse (Неразумно)** — спонтанные импульсивные траты, доставленные на эмоциях или от скуки.

*Интерактивный радар наглядно показывает соотношение и предупреждает, если доля импульсивных покупок превышает норму.*

---

### 2. 🏆 Геймификация и Зал Ачивок
* **Система уровней и XP**: от *«Новичка бюджета»* до *«Финансового Мудреца (Financial Sage)»*.
* **Стрики (Streaks) 🔥**: счетчик дней подряд без единой импульсивной покупки.
* **Трофеи и ачивки**:
  * 🛡️ *«Холодный расчёт»* (3 дня без импульсов)
  * ⚔️ *«Железный контроль»* (7 дней без импульсов)
  * 🧘 *«Дзен самурая»* (14 дней осознанного потребления)
  * 🌐 *«Мультивалютный магнат»* (счета в 2+ валютах)
  * 🐷 *«Хранитель капитала»* (открытие накопительного счета)
  * 🔄 *«Капиталовложение»* (межсчетовой перевод)
* **Салют из конфетти** при каждом повышении уровня и получении трофея!

---

### 3. 💳 Мультивалютность и Счета любых банков
* Поддержка **любых валют**: `RUB (₽)`, `USD ($)`, `EUR (€)`, `USDT (₮)`, `KZT (₸)`, `GEL (₾)`.
* **Сводный капитал (Net Worth)**: пересчитывает все сбережения и остатки карт по актуальным обменным курсам в базовую валюту.
* **Управление счетами**: редактирование балансов (✏️), добавление новых банков (➕) и удаление (🗑️).
* **Межсчетовые переводы**: переводы между своими счетами с автоматической конвертацией курсов без искажения статистики расходов и доходов.

---

### 4. 🔒 Приватность и Google Drive
* **100% Local-First**: приложение работает полностью автономно без бэкенда.
* **100% Офлайн**: встроенный Service Worker кэширует всё приложение — вы можете вносить траты в самолете или метро без интернета.
* **Свой файл бэкапа**: сохранение и восстановление одним кликом (`xpance_vault.json`).
* **Google Drive Sync**: возможность прямой синхронизации с личным Google Диском через Google OAuth.

---

### 5. 📱 PWA для смартфонов
* Идеально адаптировано под экраны мобильных устройств (включая флагманы Samsung Galaxy S24 Ultra, iPhone и др.).
* Устанавливается прямо из браузера как нативное приложение на главный экран смартфона без магазинов приложений.
* Удобная нижняя панель навигации (Ввод • Счета • Радар • Ачивки).

## 🛠 Быстрый старт (Локальная разработка)

Требуется установленный [Node.js](https://nodejs.org/) (версия 18+).

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/<YOUR_USERNAME>/xpance.git
cd xpance

# 2. Установите зависимости
npm install

# 3. Запустите локальный сервер
npm run dev
```

Приложение откроется по адресу: `http://localhost:5173/`

Для доступа со смартфона в локальной Wi-Fi сети используйте адрес сети, выведенный в консоли Vite (например, `http://192.168.1.X:5173/`).

## 🌐 Бесплатный деплой на GitHub Pages

В репозиторий уже встроен готовый рабочий процесс GitHub Actions:

1. Создайте публичный репозиторий на GitHub (например, `xpance`).
2. Привяжите удаленный репозиторий и сделайте push:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/xpance.git
   git branch -M main
   git push -u origin main
   ```
3. Откройте ваш репозиторий на GitHub: **Settings** → **Pages** → в пункте **Build and deployment / Source** выберите **GitHub Actions**.
4. Через пару минут приложение будет доступно по адресу:
   `https://<YOUR_USERNAME>.github.io/xpance/`
5. Откройте эту ссылку на телефоне и нажмите **«Установить приложение»**!
